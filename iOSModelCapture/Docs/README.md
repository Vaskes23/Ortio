# GuidedCapture Documentation

This DocC catalog provides developer documentation for the **iOSModelCapture** sample.

## Project structure

- `Common/` – shared configuration files, resources and utilities
- `Docs/` – DocC based developer documentation (this directory)
- `Feature/` – data models, mocks and the presentation layer
- `GuidedCapture.xcodeproj/` – Xcode project configuration
- `Preview Content/` – assets used in SwiftUI previews
- `Tests/` – integration and unit tests

For more details on running the sample app and the rest of the repository layout, see the root `README.md`.

## Running the sample

The app must be installed on a physical device equipped with a LiDAR scanner, an A14 Bionic chip or later, and iOS or iPadOS 17 or newer.
